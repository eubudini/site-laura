## 2. O que foi corrigido (P0/P1 confirmados + P2 de baixo risco)

Todos verificados adversarialmente e revalidados no browser (390 e 1440px).

### Performance
- **LCP do Hero (PERF-1):** a H1 e a foto (elemento LCP) animavam a partir de `opacity:0`
  via framer-motion, só pintando após a hidratação. Trocado para animação **só de transform**
  (y/scale) com opacity 1 desde o SSR. Entrada editorial preservada. **LCP 2.56s → 0.88s.**
- **Vídeo do Manifesto (PERF-2):** `.mov` de 37MB/1080p (sem playback garantido fora do Safari)
  → **mp4 H.264 720p de 4,6MB** + poster + `preload="metadata"`. Playback universal, mesmo visual.
- **Foto do Contato (PERF-3):** fonte de 11MB → versão web de **600K** (original preservado).

### Acessibilidade (Lighthouse 96 → 100)
- **Contraste AA (A11Y-1, A11Y-2):** 10 elementos abaixo de 4.5:1 medidos em Planos e Footer →
  ajustados mantendo a paleta dourada (uso de `--gold`/`--gold-text` e luminância dos cinzas).
- **prefers-reduced-motion (A11Y-3, A11Y-4):** pulso infinito do botão WhatsApp e contagem
  animada do Counter agora param/mostram valor final quando o usuário pede menos movimento.
- **Touch targets (DS-3):** links do Footer com alvo de 36px (passa AA 24px) e ícones sociais
  com área clicável de 44×44 (quadro visual de 38×38 preservado).

### Responsividade / Conversão
- **Retrato no Contato no mobile (RESP-1):** a foto sumia (`display:none`) justamente no ponto
  de fechamento (>60% do tráfego). Agora aparece compacta (240px) acima do CTA — presença
  humana restaurada no momento da decisão.

### Design System
- **Footer refatorado (CODE-6, DS-2, DS-4):** era o pior ofensor — hover via JS inline
  (`onMouseEnter/onMouseLeave`, quebrava hover por teclado) + dezenas de inline styles com
  números mágicos. Migrado para classes + tokens + hover/`:focus-visible` via CSS. Visual idêntico.
- **DESIGN_SYSTEM.md (DS-1):** documentava Bodoni Moda/DM Sans; o código usa **Fraunces + Inter Tight**
  (variáveis legadas). Tabela corrigida + nota explicando o descasamento.

### SEO
- **OG/Twitter image (SEO-1):** compartilhamentos no WhatsApp/Instagram/LinkedIn não geravam
  preview visual. Adicionada imagem real (laura-hero.jpg 720×1280).
- **Schema Person (SEO-2):** enriquecido com `description`, `email` e `telephone` — **só dados
  reais já públicos no site** (nada inventado). Reforça o sinal de autoridade para o Google.

### Limpeza
- Removido arquivo morto `lib/use-reduced-motion 2.ts` (duplicata de sync do macOS).

## 3. PENDÊNCIAS DA LAURA — o ponto mais alavancável para R$50k/mês

> Estes são os achados de maior impacto em conversão, mas dependem de **dados reais que só a
> Laura tem**. Nada foi inventado nem alterado aqui. **Recomendação: resolver isto primeiro** —
> é o que separa um site bonito de um site que fecha cliente premium com confiança.

1. **[CRÍTICO] Números de resultado são provisórios e estão expostos como fato.**
   `data.ts` traz o comentário literal "DADOS PROVISÓRIOS: atualizar com Laura". Os stats
   ("+14 marcas", "+418% crescimento médio", "+59M views", "+4327 leads") e as métricas dos
   cases (Brunnen 8K→47K +487%; Mariana 42K→198K +371%) **não estão verificados** — e o
   disclaimer que existia foi removido. O Hero repete "+14 marcas · +418%" na primeira dobra.
   → **Pergunta para a Laura:** quais desses números são reais e auditáveis? Os que ela
   confirmar, a gente mantém; os que não, suavizamos para faixas honestas ou linguagem
   qualitativa. Cliente premium pune número que não bate.

2. **Mockups "Antes/Depois" do Instagram são gerados por código** a partir desses números
   provisórios (não são prints reais), sob o rótulo "transformações reais". Depois de (1):
   ou prints reais (anonimizáveis) ou só com números confirmados.

3. **Faltam depoimentos nominais** (citação + nome + marca). Para público premium, a fala de
   uma cliente conhecida converte mais que qualquer número. → A Laura precisa fornecer 2–3
   depoimentos autorizados (texto, nome, @). Não escrevo depoimento.

4. **"H.STERN" na régua de marcas atendidas** (BrandMarquee) — não consta na lista de clientes
   conhecidos da Laura. → Confirmar se é cliente real antes de manter (risco de overclaim).

5. **Fotos internacionais atribuídas a "Zaira Nara" e "Camila Coutinho"** (pessoas reais
   famosas) nas legendas. → Confirmar se as imagens/atribuições são autorizadas.

6. **Régua de marcas usa wordmarks tipográficos, não logos reais** (a estrutura já suporta
   `logo`). → Coletar PNGs transparentes das marcas autorizadas eleva muito a autoridade.

7. **Âncora de valor em "Investimento"** — a seção Planos não tem preço nem faixa. Opcional:
   "Projetos a partir de R$X/mês" (valor real definido pela Laura) qualifica o lead sem
   tabela de preço.

8. **Formulário de captura** — hoje a conversão é 100% outbound (WhatsApp/IG/e-mail). Decidir
   com a Laura se quer um formulário curto on-page (nome/marca/mensagem → e-mail/CRM).
